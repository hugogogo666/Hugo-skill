# 分类速查

## 词根
词根是买家想购买的产品形态，不是属性或场景。判断顺序：主体名词 → 核心结构 → 工作/饮用方式 → 直接替代性。

## 相关性
- R3：可直接替代目标产品。
- R2：需求高度重叠但有规格或结构差异。
- R1：场景相关但偏流量风险较高。
- R0：购买对象、用途或形态明显不同。

## 层级
- L1：核心产品形态。
- L2：产品形态+属性/规格。
- L3：功能/痛点/场景。
- L4：人群/事件/组合长尾。

## 广告
- P0：Exact。
- P1：Exact/Phrase。
- P2：低预算Phrase/Broad。
- P3：观察或否定。

## Listing
标题优先L1/L2；五点覆盖L2/L3；A+、图片、视频覆盖功能、场景、痛点和人群；品牌竞品和错配词不写入前台文案。
