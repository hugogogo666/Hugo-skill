# Ozon 家居用品 → 1688 货源匹配总控

## 总原则

本Skill整合两个阶段，但必须严格按顺序执行：

**阶段一：Ozon低评价家居用品筛选 → 用户确认选品 → 阶段二：1688以图搜款货源匹配。**

阶段一未完成，或用户没有明确确认候选商品前，禁止调用1688图片搜索。不得把两个阶段并行执行，也不得因为用户要求“直接搜图”而跳过选品确认。

只使用已接入的数据接口和用户已有文件；不打开Ozon/1688前台，不使用浏览器网页抓取，不执行跟卖、上架、采购、促销、改价或利润计算。

## 阶段状态机

使用以下状态控制流程：

1. `SCREENING_REQUIRED`：没有可用Ozon候选文件，先执行阶段一。
2. `SCREENING_COMPLETED`：阶段一已生成候选Excel/Markdown，但尚未得到用户确认；只能展示摘要并请求确认。
3. `SELECTION_CONFIRMED`：用户明确确认要对哪些商品搜图；才能进入阶段二。
4. `IMAGE_MATCHING_COMPLETED`：已完成1688搜图并生成匹配结果。

明确确认包括：“确认”“开始搜图”“对这30个商品搜图”“继续第二阶段”等。仅说“帮我看看”“继续处理”但未指明候选范围时，不得默认进入阶段二，应再次确认范围。

## 阶段一：Ozon家居用品低评价筛选

### 数据调用

优先检查当前可用的Ozon数据接口；没有直接工具时先检查mcp_broker并发现broker-managed Ozon数据源。可使用已安装的Ozon标准接口Skill。不得要求用户提供token作为第一步，也不得改用Ozon前台网页。

### 默认筛选规则

- 一级类目：家居用品；
- 只保留实物商品和正常销售商品；
- 评价数必须小于1000；
- A级：1—100条，优先20—100条；
- B级：101—500条；
- C级：501—999条；
- 0评价：待验证；
- 评价数为空、异常或商品名称/类目/商品标识缺失：按规则排除或放入待验证；
- 排除大型家具、家电/带电商品、化学液体、食品、药品、危险器械、医疗器械、服务和虚拟商品；
- 去重优先按商品卡ID、商品ID、SKU、商品链接；
- 缺失字段填写“数据源未提供”，不得猜测。

### 阶段一输出

生成：

- `Ozon家居用品低评价候选商品.xlsx`
- `Ozon家居用品低评价商品筛选总结.md`

Excel至少包含：全部候选商品、A级优先、B级备选、C级备选、待验证、1688搜图优先30款、细分类目统计、排除统计。

阶段一完成后必须向用户汇报：候选总数、A/B/C/待验证数量、1688搜图优先数量、主图可用数量，以及缺失字段。然后停止，等待用户确认。

## 阶段二：1688以图搜款

### 进入条件

只有同时满足以下条件才能执行：

1. 阶段一候选文件存在；
2. 选品范围明确；
3. 用户已明确确认进入1688搜图；
4. 商品有公网主图URL，或已明确标记图片缺失并允许跳过。

默认优先处理阶段一的“1688搜图优先30款”。如果用户指定其他商品，以用户指定范围为准。

### 数据调用

使用1688图片搜索标准接口：

- 接口代码：`ali1688_product_search_from_image`
- 请求：`POST /wmapi/v1/sorftime/ali1688-product-search-from-image`
- 请求体：`{"image_url": "商品主图URL"}`
- 认证从`WENMAI_API_KEY`或`WENMAI_SECRET_KEY`读取；不得在文件和回复中暴露密钥。

优先使用商品主图、白底图或主体清晰图。图片URL缺失、无效或不可公开访问时，记录“图片缺失，无法执行以图搜图”，不得编造替代图片。

### 搜索与匹配

每个Ozon商品默认保留最多3个1688候选，并按商品ID/商品链接去重。记录：标题、链接、主图、商品ID、价格、MOQ、是否一件代发、发货地、服务评分、30日销量、复购率、店铺名和商家标签等实际返回字段。

匹配等级必须保守：

- **S级完全同款**：图片、结构、规格/型号、材质、配件数量均有充分证据。仅凭图片排名禁止判S；
- **A级高度相似**：外观和核心功能高度一致，差异主要可能是颜色、包装或小细节；
- **B级可替代**：功能或品类一致，但结构、尺寸、材质或配件存在差异/不确定；
- **C级不匹配**：仅关键词相关、功能不同或明显不是同类，排除。

供应商排序：匹配证据 → 规格一致性 → 价格有效性 → MOQ/代发 → 工厂或实力商家标签 → 服务评分/销量。

### 阶段二输出

生成：

- `Ozon_1688图片货源匹配结果.xlsx`
- `Ozon_1688图片货源匹配结果.md`

Excel至少包含：全部匹配结果、S级完全同款、A级高度相似、未找到货源。

缺失价格、MOQ、供应商、发货地或代发信息时填写“未知”或“数据源未提供”，不做推断。极低价格可能只是单个配件价或阶梯价，不直接当作完整套装成本。

## 异常与中断

- 接口超时、连接异常、非成功响应：对当前商品记录“当前数据暂不可获取”，继续处理其他商品并保存中间JSON；
- 搜索无结果：记录“未找到匹配供应链”；
- 图片缺失：跳过图片调用并记录原因；
- 阶段一字段缺失：不因此中断全量筛选，但在报告中列明；
- 阶段二不得回头重新检索Ozon，除非用户另行明确要求。

## 推荐执行方式

阶段一完成后，先向用户展示摘要并等待确认。获得确认后运行：

```bash
python3 scripts/pipeline_guard.py --input <阶段一Excel> --stage matching --confirm
```

也可以只做阶段状态检查：

```bash
python3 scripts/pipeline_guard.py --input <阶段一Excel> --stage check
```

脚本只负责验证输入和阶段门禁；实际数据调用和报告生成仍按本Skill的两阶段规则执行。
